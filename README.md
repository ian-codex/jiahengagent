## 本地预览

直接双击 `index.html` 即可查看页面。

注意：本地用 `file://` 打开时，询盘表单无法真正发信（浏览器安全限制），
会提示「当前为本地预览模式」。表单发信需要放到支持 PHP 的服务器上测试。

## 询盘邮件配置

打开 `config.php`，只需要改一处：

```php
'smtp_pass' => '把这里换成163邮箱授权码',
```

获取方式：登录 163 邮箱网页版 → 设置 → POP3/SMTP/IMAP → 开启 SMTP 服务 →
按提示验证手机 → 复制页面显示的 16 位授权码，粘贴到上面单引号内。保存即可。

- 发信账号 / 收信邮箱：`xiaoyuge444@163.com`
- SMTP 服务器：`smtp.163.com`，端口 `465`（SSL）

邮件主题格式：`【吉邦精密官网】××× 的询盘`，正文包含访客填写的
姓名、公司、电话、邮箱、所属行业和需求说明。

## 上线

详见 `上线指南.md`。核心三步：买阿里云虚拟主机 → 用 FTP 把本目录文件传到
网站根目录 → 在 `config.php` 填好授权码并测试表单。
