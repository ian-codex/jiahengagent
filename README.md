# 吉邦精密官网（新站）

惠州市吉邦精密技术有限公司官网的重设计版本。纯静态站点，无需数据库、无需构建步骤，
上传到任意支持 PHP 的空间即可运行。

- 在线预览：https://ian-codex.github.io/jiahengagent/
- 公司官网参考：https://www.jbcasting.com
- 品牌主色：`#E94929`（沿用原官网品牌红橙）
- 技术栈：原生 HTML / CSS / JavaScript + 一个极简 PHP 邮件接口

## 在线预览说明

`https://ian-codex.github.io/jiahengagent/` 是通过 GitHub Pages 自动发布的版本，
用于给同事、客户查看设计效果。

GitHub Pages 只能放静态文件、跑不了 PHP，所以这个在线版**不会真正发信**，
页面上的询盘表单会提示「在线演示版」。真正收询盘的版本需要部署到支持 PHP 的服务器，
步骤见 `上线指南.md`。

修改页面后推送到本仓库的 `main` 分支，线上地址会在 1 分钟左右自动更新。

## 询盘邮件配置

仓库里放的是模板文件 `config.sample.php`。使用时把它复制一份、改名为 `config.php`，
再填写内容即可（`config.php` 已在 `.gitignore` 中排除，不会上传到 GitHub，
避免邮箱授权码泄露）。

模板里只需要改这一处：

```php
'smtp_pass' => '你的163邮箱授权码',
```

获取方式：登录 163 邮箱网页版 → 设置 → POP3/SMTP/IMAP → 开启 SMTP 服务 →
按提示验证手机 → 复制页面显示的 16 位授权码，粘贴到上面单引号内。保存即可。

- SMTP 服务器：`smtp.163.com`，端口 `465`（SSL）
- 发信账号 / 收信邮箱：在 `config.php` 里自行填写

邮件主题格式：`【吉邦精密官网】××× 的询盘`，正文包含访客填写的
姓名、公司、电话、邮箱、所属行业和需求说明。
